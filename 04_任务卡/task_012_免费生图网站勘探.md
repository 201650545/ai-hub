# 任务卡 012：免费生图网站勘探与注入可行性验证

## 执行模型：🟢 Gemini 3.6 Flash

## 目标
勘察大陆可访问的免费 AI 生图网站，逐一验证「opencli 注入提示词 → 生成 → 提取下载」的技术可行性，产出可用站点清单与组件规则卡草稿，扩充图片组件的站点池。

## 背景
组件编排器（见 `06_组件编排器/组件编排器架构设计.md`）的图片组件依赖浏览器注入生图。已规划 3 个初始站点（豆包生图 / ChatGPT 镜像 / 通义千问），但需要更多备用站点提高可用性——单站点审核失败或排队时需要 fallback。

## 勘探要求

### 1. 站点搜集
找出 **8-12 个**候选站点，要求：
- 大陆可直接访问（无需翻墙）
- 免费或有大额免费额度
- 网页端可通过输入提示词生图

候选方向（不限于）：即梦、豆包、通义万相、文心一格、讯飞星火、商汤秒画、无界AI、哩布哩布、触站AI、 Vega AI 等。

### 2. 逐站验证（核心）
对每个站点，用 opencli 实测完整链路：
```
opencli browser probe_<站点> open <站点URL>
→ eval 探测提示词输入框选择器
→ 注入测试提示词（"a red apple on a table, flat cartoon style"）
→ 提交并轮询等待生成（记录实际等待时长）
→ 提取图片（记录 src 类型：https 直链 / blob / base64）
→ 下载到 D:\项目\06_组件编排器\勘探样例\<站点>.png
```

### 3. 逐站记录
| 字段 | 说明 |
|------|------|
| 站点名 / URL | |
| 是否需登录 | 免登录最佳 |
| 输入框选择器 | 实测值 |
| 提交方式 | Enter / 按钮选择器 |
| 平均生成时长 | 秒 |
| 图片提取方式 | img_src / blob_canvas / base64 |
| 免费额度 | 每日次数或额度 |
| 注入可行性 | ✅ 可行 / ⚠️ 需登录 / ❌ 不可行（说明原因） |

### 4. 产出
1. **勘探报告**：`06_组件编排器/生图网站勘探报告.md`（上表全量 + 推荐排序）
2. **规则卡草稿**：每个 ✅ 可行站点一份 `组件规则卡/image_gen_<站点>.yaml`（按既有 4 张规则卡的 schema）
3. **样例图**：`06_组件编排器/勘探样例/` 每站一张实测生成图

## 验收标准
- 至少 3 个站点达到「✅ 可行」（注入→生成→下载全链路通）
- 报告含明确的推荐优先级排序（综合考虑：免登录、速度、额度、画风）
- 规则卡草稿可直接被图片组件加载
- 勘探样例图真实存在且可打开

## 注意
- opencli daemon 已在运行；新会话命名 `probe_<站点>`，勘探完可保留
- 遇登录墙标注 ⚠️ 即可，不代替用户登录（豆包/通义已有会话可复用）
- 尊重站点条款：仅验证技术可行性，不批量薅取
