## 三、Bug ① 根因与修法

**根因（读码确认，非任务书猜测的三个方向）**：特异性战争——
`:root[data-style="liquid"] .glass{position:relative}`（特异性 0,3,0）压过 `.pal-pop{position:absolute}`（0,1,0）。
liquid 模式下弹窗被拉回文档流，在 `.pal-wrap` 内占位 → 撑高 `.h-top` flex 行并重新居中 → 🎨 按钮上蹿；收起 `display:none` 回流复位。动画 transform / 弹簧 --ty / hover 回弹均只作用于弹窗自身，无法推动按钮，已全部排除。全文件 40+ 个 `.glass` 元素中 `.pal-pop` 是唯一绝对定位者，故只它有症状。

**修法（1 行，作用域内）**：`:root[data-style="liquid"] .pal-pop.glass{position:absolute}`（0,4,0，顺序无关）。

## 四、变更清单（全部在 `:root[data-style="liquid"]` 作用域 + `.gfx` FX 层）

1. **Bugfix**：新增 `.pal-pop.glass{position:absolute}` 还原定位。
2. **玻璃基座（浅色）**：saturate 118%→142%、边 alpha .16→.30、上高光 1px→1.5px/.95、底阴加深、新增左右侧缘**彩色 inset 色散**（左粉右蓝各 1.5px）。
3. **菲涅尔虹彩边环**：`.gfx-e::before` conic 由纯白高光改为低饱和色散（冰蓝 .48 / 粉 .30 / 暖金 .18 / 青 .24），仍随 `--edge-rot` 视角流转；叠加 `lg-edge-breathe` 9s **opacity 呼吸**（.52↔.86）。
4. **静止呼吸层（新增 `.gfx-b`）**：超宽柔光 16s 极慢漂移，`lg-sheen-drift` **纯 transform** 合成器动画，无 rAF；fxEnhance 注入节点并把 glint/sweep 子索引 +1。
5. **光斑/扫光微彩**：`.gfx-g` 增粉青外围、`.gfx-s` 增暖粉尾迹。
6. **暗色深邃黑玻璃**：底色 #0f1115→#0b0d12 / #0a0c10→#04060a；玻璃 rgba(24,27,35,.60)→(10,12,17,.44) 渐变、saturate 135%、blur 24px；边环换冷色霓虹配方（冰蓝 .55/紫 .34/青 .28）；投影加深；光斑 opacity 微升。
7. **reduced-motion**：`lg-edge-breathe` / `lg-sheen-drift` 全关，`.gfx-b` 隐藏——保护完整。
