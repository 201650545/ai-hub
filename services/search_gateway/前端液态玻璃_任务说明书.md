## 你要解决的两件事

### ① Bug：调色盘弹窗弹出时按钮「向上跳」

液态玻璃风格（`data-style="liquid"`）下，点右上角 🎨 调色盘按钮 → 弹窗弹出 → 按钮向上蹿一下；收起后复位。

**不要直接采信下面的猜测**——自己读相关代码确认根因再修：
- 相关元素：`.pal-btn` / `.pal-pop`（弹窗带 `class="glass"`）、`.pal-wrap`。
- 相关 CSS：`.pal-pop.on{animation:pop .18s}` + `@keyframes pop{from{...transform:translateY(-6px)...}}`，以及 `.glass` 规则里的 `transform:perspective(900px) translate3d(var(--tx),var(--ty),...)`。
- 相关 JS：`fxEnhance()` 弹簧引擎会往 `.glass` 元素写 `--tx/--ty/--rx/--ry`。
- 你要判断：是动画 transform 与 .glass transform 冲突？是弹簧 `--ty` 让弹窗上移？还是 hover scale 回弹？或别的？**以你读码的结论为准。**
- 修法要求：保留 FX 光学层，最小改动，别砍功能。

### ② 高级感：当前液态玻璃「不够高级」

用户原话：**「感觉这个不是很高级啊，并没有苹果那种炫彩 3D 液态玻璃风格。」**

当前实现偏「克制中性」——底色冷石中性、玻璃 hairline 发丝边、文字恒中性、色相只在壁纸空气和交互。**过度克制反而显平淡**，缺苹果 visionOS 那种「炫彩、3D 厚度、高折射、活的光泽」。

**你不被规定怎么做**。自己读当前的液态玻璃 CSS 令牌块（` :root[data-style="liquid"]` 一段）和 `.gfx` FX 三层、`fxEnhance` 弹簧，找出哪些当前值让它「显廉价」（饱和度？边太细？高光太弱？折射没有彩边？），自己定升级方向并落地。

## 你必须做的：中途问用户想要什么感觉

**在动手实现之前，先把自己的诊断 + 2~3 个具体的视觉方向选项抛给用户，让用户拍板「到底想要哪种感觉」。** 用户要参与审美方向决策，不要你自己闷头改完才给看。

可以参考的提问维度（不是让你照搬，是你自己判断后组织语言问用户）：
- 「炫彩」要到什么程度？——微彩边（菲涅尔随视角变色）／明显虹彩／还是保持中性只强 3D 厚度？
- 「3D 厚玻璃」要不要明显的边斜面 + 内高光 + 底阴？
- 静止时是否要微呼吸光泽？还是只在指针交互时才动？
- 暗色模式下要不要更「深邃黑玻璃」感？

用户回答后再实现。

## 硬约束（不许破）

- **单文件、无构建步骤**。改完直接刷新可见（网关每请求重读文件；浏览器可能要 Ctrl+F5）。
- **性能红线**：指针移动只动 `transform`/`opacity`，**绝不**在 pointermove 里动 `background`/`border-radius`/`filter`/`box-shadow`。
- **作用域隔离**：改动只在 `:root[data-style="liquid"]` 作用域 + `.gfx` FX 层。其他 4 套风格（monet/vangogh/ink/modern）**不许受影响**。
- **配色架构不动**：`accent` 仍是「色系种子」，文字恒中性——但**允许玻璃材质本身更炫**（边环菲涅尔彩、内高光更强、折射更明显）。
- `prefers-reduced-motion` 全关动画；后台标签不跑 rAF。
- 不要往文件里写任何 API key / 密钥。
