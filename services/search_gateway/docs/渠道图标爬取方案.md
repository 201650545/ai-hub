# 方案：API 转发网关渠道官网图标爬取与更新

> 本方案自包含，交给另一个 AI 直接执行即可，无需访问本机其他文件。

## 一、任务目标

为 API 转发网关的 **11 个渠道** 下载官方 logo / favicon，保存为 PNG 图片，并更新渠道配置，使网关管理页面显示官网图标（替代现在的 emoji 占位图标）。

## 二、背景信息

- 网关管理页：`http://localhost:3100`（本机）
- 网关鉴权：`Authorization: Bearer gyt2005228`
- 图标存放目录：`D:\项目\services\search_gateway\web\img\brand\`
- 渠道配置文件：`D:\项目\data\search_gateway\channels.json`
- 网页通过 `/img/brand/<渠道id>.png` 访问图标；渠道配置里 `icon` 字段填 `/img/brand/<渠道id>.png` 即可显示图片
- **已完成**：`bai`（B.AI）、`gmi`（GMI Cloud）两个渠道的图标已搞定，**不要动它们**
- 网关对 `channels.json` 是 mtime 感知缓存，改文件后下次请求自动生效，**无需重启网关**

## 四、图标获取方法（按优先级）

1. **官网 favicon**：直接下载 `https://<官网域名>/favicon.ico`（注意：很多站点的 .ico 实际是 PNG 格式，下载后按内容判断，不要按扩展名）
2. **官网 HTML 里找图标**：抓取官网首页 HTML，找 `<link rel="icon">`、`<link rel="apple-touch-icon">`、`<link rel="shortcut icon">` 标签的 href，下载对应文件
3. **Google favicon 服务**（兜底）：`https://www.google.com/s2/favicons?domain=<官网域名>&sz=64`，返回 PNG
4. **品牌首字母生成**（仅当官网实在找不到时）：用品牌主色 + 首字母做一个简单方形 PNG 图标

## 五、执行步骤

对每个渠道重复以下步骤：

1. 按「图标获取方法」下载该渠道的官方图标
2. 转成 **PNG 格式**（透明背景优先，正方形，建议 64×64 或以上；若拿到 .ico 且内含多尺寸，取最大尺寸导出 PNG）
3. 保存为 `D:\项目\services\search_gateway\web\img\brand\<渠道id>.png`
4. 编辑 `D:\项目\data\search_gateway\channels.json`，把该渠道 `custom_channels` 或内置渠道定义里的 `icon` 字段改为 `"/img/brand/<渠道id>.png"`
   - 注意：内置渠道（非 custom_channels）的 icon 在代码 `D:\项目\services\search_gateway\channels.py` 的 `CHANNELS` 字典里，需要同步改代码里的 icon 字段
   - 判断方法：`channels.json` 的 `custom_channels` 里有该 id 就是自定义渠道（改 json），否则是内置渠道（改 channels.py 的 CHANNELS 字典）

## 六、验证

1. 图片可访问：请求 `http://localhost:3100/img/brand/<渠道id>.png`（带鉴权头）应返回 HTTP 200 且 Content-Type 为 image/png
2. 配置已生效：请求 `http://localhost:3100/api/health`（带鉴权头），检查该渠道的 `icon` 字段为 `/img/brand/<渠道id>.png`
3. 浏览器打开 `http://localhost:3100` 渠道管理页，确认图标显示为官网 logo

## 七、注意事项

- **不要动** `bai` 和 `gmi` 两个渠道的图标（已完成）
- 图标字段支持 emoji 或 `/img/…` 图片路径；若某渠道官网实在无图标，保留原 emoji 并在完成记录里注明
- `channels.json` 是 UTF-8 编码，编辑时保持中文正常，不要出现乱码
- 内置渠道改 `channels.py` 后需要**重启网关**才生效（`python D:\项目\services\search_gateway\api_gateway.py`，工作目录 `D:\项目\services\search_gateway`）；自定义渠道改 json 无需重启
- 下载时注意网络超时，单个图标失败不要中断整体任务，记录后继续

### 耗时坑位记录（供后续参考）
- 下载时按内容判断格式很重要：volcengine/sensetime 等 favicon.ico 实际返回 HTML 或 404，需 HTML 扫描找真实图标路径。
- ICO 转 PNG：System.Drawing 在受限环境不可用；用 Node.js 解析 ICO（BMP 条目高度需减半，因含 AND mask）+ `zlib.deflateSync` 手工编码 PNG 可行。
