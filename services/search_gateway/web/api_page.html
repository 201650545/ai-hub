🍒 Cherry Studio 接入
供应商类型:  OpenAI
API 地址:    http://localhost:3100/v1
API 密钥:    留空即可(或填任意字符)
模型:        自动获取(/v1/models),或手动添加如 deepseek-v4-flash
🐍 Python (openai SDK) 接入
from openai import OpenAI

client = OpenAI(base_url="http://localhost:3100/v1", api_key="none")
resp = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
⌨️ curl 接入
curl http://localhost:3100/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"你好"}]}'
💡 响应头 X-Routed-Channel 会告知本次请求实际路由到的渠道;模型名会自动映射为各渠道的实际名称(如 deepseek-v4-flash → deepseek-ai/DeepSeek-V4-Flash-0731)。
🔌 API 端点OpenAI 兼容
端点说明
GET /api/health全部渠道健康状态(含启停/ key 池)
GET /api/models所有模型 + 每个模型的支持渠道
GET /api/model_providers?model=xxx反查支持某模型的渠道(已排序)
GET /api/channels渠道列表 + key 状态
PUT /api/channels/<id>/enabled渠道启用/停用 {"enabled": true|false}
POST /api/channels/<id>/test渠道测活(ZSCC 禁测)
POST /v1/chat/completions对话 · 多渠道 fallback · 支持 stream
GET /api/routing读取全部手动路由规则
PUT /api/routing设置某模型的渠道顺序(搭积木)
DELETE /api/routing?model=清除规则,恢复自动排序
GET /api/gateway-info接入信息(本机/局域网地址、鉴权)
PUT /api/gateway-key设置/变更/关闭网关 API key {"key":"..."}(空串=关闭)
GET /api/model-overrides自定义模型 + 隐藏模型配置
POST /api/model-overrides/custom新增自定义模型 {name, channel, model}
DELETE /api/model-overrides/custom?name=删除自定义模型
PUT /api/model-overrides/hidden设置隐藏模型列表 {hidden: [...]}
GET /api/route-log最近 50 条路由决策
响应头 X-Routed-Channel路由到的渠道 ID(每次 /v1/chat/completions 返回)
响应头 X-Resolved-Model实际转发给上游的模型名
