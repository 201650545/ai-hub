# 词境挖空 · 主动输出训练器

> 需求来源：小红书调研《笔记① 小说刷词》→ 产品需求文档 §一「项目一：词境挖空」
> 定位：把喜欢的任何内容（小说/文章）变成填空练习——**主动写出来，比认出来记得更牢**。

## 一句话

**内容 → 随机挖空 → 打字写出答案 → 即时判定 → 错题本**

## 与原型「词境阅读」的区别

原型是「点词弹卡」（被动认），本项目按需求文档 §1.7 升级为「挖空 + 主动写」（主动输出）——记忆强度更高。

## 如何运行

1. 启动本地搜索网关（:3000）：`cd D:\项目 && python -m runtime.cli start --all`
2. 浏览器打开 `http://localhost:8000/word-cloze/index.html`（已挂载到中央平台）
3. 三种内容来源任选：内置示例 / 粘贴文本 / ✨ AI 一句话找内容

## 功能

| 能力 | 说明 |
|------|------|
| 内容供给 | 内置示例 + 粘贴文本 + **AI 一句话生成 3 篇候选**（多方案比选，用户决策） |
| 随机挖空 | 英文实义词挖空，密度可调（10%/20%/33%），去重、跳过短词/全大写缩写 |
| 答案输入 | 打字填空，回车跳到下一个（手写识别属阶段 3，见下） |
| 判定 | 与标准答案比对，容错大小写/标点/复数，正确绿 / 错误红 + 显示正确答案 |
| 错题本 + 统计 | 本轮错题自动归集，正确/错误/未答计数 |

## 架构

```
内容（示例/粘贴/AI 生成）
   │  tokenize 分词 → 过滤(短词/缩写/去重) → 按密度采样 → 挖空
   ▼
练习区（原文挖空处渲染 <input class=blank>，答案存 data-word）
   │  用户输入 → normalize(小写+去标点) 比对
   ▼
判定 → 绿(对)/红(错) + 错题本 + 计数
```

AI 内容供给走本地网关 :3000（`gemini-2.5-flash`，一句话 → 3 篇候选 JSON → 选一篇进入挖空）。
