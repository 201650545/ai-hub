# AI Hub 前端重构方案 —— 苹果官网风 · 极简线条

> 目标：统一 4 个前端（中央平台首页 / dashboard / AI 画布 / 词境挖空）为「苹果官网风 + 极简线条」。
> 本文档是**执行规格**，供接手模型照做。所有色值/字号/间距/圆角已给死，不需要再发挥。

---

## 0. 现状诊断（为什么难看）

| 前端 | 现状 | 问题 |
|------|------|------|
| 中央平台首页（server.py 内联 HTML） | 深色 `#0a0a0f` + 卡片 `#14141f` | 内联样式、卡片粗糙、无设计语言 |
| dashboard 管理面板 | 深色 `#090a0f` + 紫色 `#6366f1` | 紫色主题突兀、与「苹果风」相反 |
| AI 画布（apps/ai-canvas） | 暖色米白画布 + 深色工具栏 | 独立风格、与其他页面割裂 |
| 词境挖空（apps/word-cloze） | 暖色 `#f4efe4` | 米黄偏旧、不精致 |

**根因**：没有统一设计系统，4 处各写各的。重构 = 建立一套 tokens + 逐页套用。

---

## 1. 设计目标

**苹果官网风**：大量留白、大标题、克制配色（白底黑字 + 单一强调色）、精致排版、平滑克制的动效。
**极简线条**：1px 细线边框、线性图标（stroke 而非填充）、视觉层级靠留白和字号而非粗框。

一句话：**「白、留白、细线、大字、一个蓝」**。

---

## 2. 设计系统（Design Tokens）—— 全局唯一真源

以下变量必须一字不差地落地到共享 CSS（见 §5），所有页面引用。

### 2.1 颜色

```css
:root {
  /* 背景 */
  --bg: #ffffff;              /* 主背景：纯白 */
  --bg-subtle: #f5f5f7;       /* 次级背景：苹果浅灰（分区/表格斑马纹） */
  --bg-elevated: #ffffff;     /* 卡片/浮层背景 */

  /* 文字 */
  --text-primary: #1d1d1f;    /* 主文字：苹果近黑 */
  --text-secondary: #6e6e73;  /* 次级文字：苹果灰 */
  --text-tertiary: #86868b;   /* 弱化文字 */

  /* 强调色（唯一主色，不允许多色） */
  --accent: #0071e3;          /* 苹果蓝：链接/主按钮/焦点 */
  --accent-hover: #0077ed;    /* 悬停 */
  --accent-subtle: #e8f1fd;   /* 蓝色浅底（选中态/信息卡） */

  /* 语义色（克制，仅状态用） */
  --success: #34c759;         /* 在线/成功（苹果绿） */
  --danger: #ff3b30;          /* 离线/错误（苹果红） */
  --warning: #ff9f0a;         /* 告警（苹果橙） */

  /* 线条 */
  --line: #d2d2d7;            /* 细线边框（苹果浅灰线） */
  --line-strong: #86868b;     /* 较强分隔线 */

  /* 深色模式（可选，用 data-theme="dark" 切换） */
}
:root[data-theme="dark"] {
  --bg: #000000;
  --bg-subtle: #1d1d1f;
  --bg-elevated: #1d1d1f;
  --text-primary: #f5f5f7;
  --text-secondary: #a1a1a6;
  --text-tertiary: #86868b;
  --accent: #2997ff;
  --line: #424245;
}
```

### 2.2 字体

```css
/* 苹果 SF Pro 字体栈 —— 不下载字体，用系统栈近似 */
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display",
             "SF Pro Text", "Helvetica Neue", "PingFang SC",
             "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

字号规范（苹果排版节奏）：

| 用途 | 字号 | 字重 | 字距 |
|------|------|------|------|
| 页面大标题（hero） | 56px | 700 | -0.015em |
| 区块标题 | 32px | 700 | -0.01em |
| 卡片标题 | 21px | 600 | 0 |
| 正文 | 17px | 400 | 0 |
| 说明/辅助 | 14px | 400 | 0 |
| 小字/标签 | 12px | 400/500 | 0 |

行高：标题 1.1，正文 1.5。

### 2.3 间距（8pt 网格）

所有间距用 8 的倍数：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`。
页面左右留白：桌面 ≥ 64px，移动 16px。区块垂直间距 ≥ 48px。

### 2.4 圆角

```css
--radius-sm: 8px;    /* 小元素/标签 */
--radius-md: 12px;   /* 输入框/按钮 */
--radius-lg: 18px;   /* 卡片 */
--radius-xl: 28px;   /* 大容器/浮层 */
```
按钮胶囊（主 CTA）用 `9999px`。

### 2.5 阴影（极克制，苹果是「轻阴影 + 细线」）

```css
--shadow-sm: 0 1px 2px rgba(0,0,0,0.04);       /* 卡片默认 */
--shadow-md: 0 4px 16px rgba(0,0,0,0.08);      /* 悬浮/浮层 */
--shadow-lg: 0 12px 40px rgba(0,0,0,0.12);     /* 弹窗 */
```
原则：**优先用细线边框（--line）表达边界，阴影只做微抬升，不做重阴影。**

### 2.6 动效

```css
--ease: cubic-bezier(0.4, 0, 0.2, 1);          /* 标准缓动 */
--ease-spring: cubic-bezier(0.32, 0.72, 0, 1); /* 强调/回弹 */
--duration-fast: 0.15s;
--duration: 0.3s;
```
原则：hover 微交互 0.15s，页面切换/展开 0.3s，**禁止花哨动画**（无弹跳、无旋转、无闪烁）。

## 3. 组件规范（所有页面复用同一套类名）

### 3.1 按钮

| 变体 | 样式 |
|------|------|
| 主按钮 `.btn-primary` | 蓝底白字，胶囊 `9999px`，padding `10px 22px`，hover 加深 + 微放大 |
| 次按钮 `.btn-secondary` | 白底 + 1px `--line` 边框，黑字，胶囊，hover 变浅灰底 |
| 文字按钮 `.btn-ghost` | 无底无框，蓝字，hover 下划线/浅蓝底 |
| 危险按钮 `.btn-danger` | 白底 + `--danger` 边框红字 |

所有按钮：`transition: all var(--duration-fast) var(--ease)`，`:active` 缩放 0.98。

### 3.2 卡片 `.card`

白底 + `--radius-lg` 圆角 + `1px --line` 边框 + `--shadow-sm` 阴影，padding `24px`。
hover：`transform: translateY(-2px)` + 边框变 `--line-strong`（**不放大阴影**）。

### 3.3 导航

- 顶部导航：白底毛玻璃 `backdrop-filter: blur(20px)` + 底部 `1px --line`，高度 52px，固定顶部。
- 导航项：14px 文字，默认 `--text-secondary`，激活 `--text-primary` + 蓝字或底部 2px 蓝线。
- 侧边栏（dashboard）：白底 + 右 `1px --line`，激活项 `--accent-subtle` 浅蓝底 + 蓝字。

### 3.4 表格

表头：14px 600 字重 `--text-secondary`，底部 `1px --line`。
行：`1px --line` 分隔（不用斑马纹，苹果极简；大数据量才用 `--bg-subtle` 斑马纹）。
单元格 padding `12px 16px`，正文 14px。

### 3.5 表单

输入框：白底 + `1px --line` 边框 + `--radius-md`，padding `10px 14px`，focus 边框变 `--accent` + 外圈 `3px --accent-subtle` 光晕（不用默认蓝色 outline）。

### 3.6 图标 —— 线性（stroke）

统一用 **line icon**（线性、1.5px 描边），不用填充图标。推荐直接内联 SVG，stroke 用 `currentColor`，尺寸 16/20/24px 三档。

## 4. 各页面重构要点

### 4.1 中央平台首页（server.py 内联 HTML）—— 最高优先级

改造 `index()` 函数返回的 HTML。目标：像苹果官网首页。

- **背景**：`--bg` 白底，去掉现在的深色 `#0a0a0f`。
- **Hero 区**：居中大标题「AI Hub」56px 700 + 副标题 17px `--text-secondary`，大量留白（上下 ≥ 96px）。
- **应用区**（AI 画布 / 词境挖空）：白底卡片 `.card`，图标用线性 SVG，卡片标题 21px，描述 14px `--text-secondary`，hover 微抬升。
- **网关区**：标题「网关」32px + 卡片网格。在线状态用 `--success` 小圆点 + 文字，离线用 `--danger`。
- **去掉**：现在的深色卡片、彩色左边框（`border-left:3px`）、emoji 大图标（换成线性 SVG）。
- **底部 footer**：14px `--text-tertiary`，细线分隔。

### 4.2 dashboard 管理面板 —— 第二优先级

改造 `dashboard/styles.css`（750 行，重写 tokens 区 + 组件类）。

- **配色**：把紫色 `--primary:#6366f1` 全部换成 `--accent:#0071e3`；深色背景换成白底浅色（或做深色模式切换，默认浅色）。
- **侧边栏**：白底 + 右细线，激活项浅蓝底。
- **统计卡**：白底卡片，大数字 32px 700，标签 14px `--text-secondary`。
- **表格**：按 §3.4 细线风格。
- **状态徽章**：在线 `--success` 浅底绿字，离线 `--danger` 浅底红字，全部用「浅底 + 深色字」的克制色块，不用纯色填充。

### 4.3 AI 画布（apps/ai-canvas/index.html）—— 第三优先级

画布工具类产品，保留「浅色画布」这个正确决策，只统一周边 UI。

- **画布区**：保持白底（已是 `#faf9f5`，可微调为 `#ffffff`）。
- **工具栏/侧栏**：从深色 `#1b1813` 改为**白底毛玻璃**（`backdrop-filter: blur(20px)` + `1px --line` 边框），图标改线性 SVG，激活态 `--accent-subtle` 浅蓝底。
- **右侧面板**：白底卡片 + 细线边框，标题 14px 600，正文 13px `--text-secondary`。
- **按钮**：主按钮（Reason/Recognise）用 `.btn-primary` 蓝底；普通用 `.btn-secondary`。

### 4.4 词境挖空（apps/word-cloze/index.html）—— 第四优先级

- **背景**：从暖色 `#f4efe4` 改为 `--bg` 白底 + `--bg-subtle` 分区。
- **字体**：从 Georgia 衬线改为苹果系统字体栈（sans-serif）。
- **文章区**：白底卡片 + 细线边框，正文 17px，行高 1.8。
- **挖空输入框**：保留「下划线」交互（这是产品特色），但颜色统一 `--accent`，focus 变蓝下划线 + 浅蓝底。
- **按钮**：主按钮 `.btn-primary`，次按钮 `.btn-secondary`。
- **判定反馈**：正确 `--success` 绿、错误 `--danger` 红（浅底 + 深字，克制）。

## 5. 技术选型与实施

### 5.1 共享 CSS 文件（关键决策）

**抽一个全局 `theme.css`**，包含 §2 全部 tokens + §3 组件类，所有页面引用，避免 4 处重复。

落地方式（推荐）：

```
services/central/static/theme.css     ← 唯一真源（design tokens + 组件类）
```

- 在 `server.py` 挂载：`app.mount("/static", StaticFiles(directory=str(BASE_DIR / "static")), name="static")`
- 首页内联 HTML、dashboard、AI 画布、词境挖空 都加：
  `<link rel="stylesheet" href="/static/theme.css">`
- 页面特有样式（画布交互、挖空输入框等）继续留在各自文件内联，但**颜色一律引用 `var(--xxx)`，不再写死色值**。

**保持无构建**：不引入 React/Vue/Tailwind/打包器。纯 CSS + 原生 JS，符合现状（单文件静态，直接挂 FastAPI），也让执行成本最低。

### 5.2 实施顺序（按优先级，每步可独立验收）

1. **建 `theme.css`**（tokens + 组件类）+ server.py 挂载 `/static`。
2. **重构首页**（server.py index 函数）—— 苹果风 hero + 应用区 + 网关区。
3. **重构 dashboard**（styles.css 换 tokens + 组件）。
4. **重构 AI 画布**（周边 UI 统一，画布交互不动）。
5. **重构词境挖空**（配色/字体/按钮统一）。
6. **深色模式**（可选，data-theme 切换，最后做）。

---

## 6. 验收标准

1. **4 个前端颜色统一**：全部走 `var(--bg/--text/--accent/--line)`，无写死色值（画布笔迹颜色除外）。
2. **一眼是苹果风**：白底、留白、细线、大标题、单一蓝 `#0071e3`。
3. **无紫色残留**：全项目 `grep` 不到 `#6366f1` / `#0a0a0f` / `#090a0f`。
4. **功能不回归**：首页入口、dashboard 6 个 tab、AI 画布识别/动画、词境挖空判定/错题本 —— 全部仍可用。
5. **响应式**：桌面/移动都正常（移动端导航折叠、卡片单列）。
6. **`tests/run_all.py` 仍全绿**（前端改动不应破坏后端 API）。

---

## 7. 关键约束（执行时注意）

- ⚠️ **只改样式，不动逻辑**：server.py 的 API 端点、dashboard 的 app.js 数据逻辑、AI 画布的动画解释器、词境挖空的挖空引擎 —— 全部保持原样，只改 HTML/CSS。
- ⚠️ **不引入外部依赖**：不引 Tailwind/Bootstrap/CDN 字体/图标库，图标用内联 SVG。
- ⚠️ **苹果风 ≠ 全是白色**：用 `--bg-subtle`（#f5f5f7）做分区，靠留白和字号建层级，不要回到「深色 + 彩色」老路。
- ⚠️ **单一强调色**：全站只有 `--accent` 一个蓝，状态色（绿/红/橙）只在「在线/离线/告警」语义处出现，不得用于装饰。
