# 资源调查任务书（交接给执行 AI）

## 一句话目标
通过**分类交互式提问**，把郭老师手头所有 AI 模型资源盘清，形成一张结构化台账，为「让不同模型干不同的事」打底。

## 背景
郭老师有多个 AI 模型资源（API 账户、Agent 工具、购买的套餐 / 镜像账号、网页版 AI、生图工具、AI 搜索等），每个有额度、会刷新、会过期。目前分散、状态不清，需要系统盘一遍。

**关键：郭老师不会一次性把所有资源告诉你，你必须按分类不断提问、边问边记。不要假设他有啥，也不要一次性问「你都有啥」。**

## 你要做什么（分类交互式提问）

### 资源类型框架（按顺序逐类问，这是你的提问清单）
1. **API 账户（直连 API key）**：OpenAI / Anthropic(Claude) / DeepSeek / Gemini / Moonshot(Kimi) / 通义千问 / 智谱 / 硅基流动 / 火山引擎(豆包API) / 文心 … 这类有没有？各是什么模型、额度怎么算？
2. **Agent 工具（编程 / 自动化 Agent）**：OpenCode Go / Codex / Cursor / Claude Code / Cline / Windsurf / Trae / Qoder … 有没有？订阅怎么算额度？
3. **购买的套餐 / 镜像站（Plus 账号、中转）**：AI问答宝(Plus多卡) / WorkBodySolo / 各种 67673 中转站 … 有没有？
4. **网页版 AI 产品**：豆包 / 智谱清言 / 文心一言 / 通义千问 / Kimi / 元宝 / ChatGPT web / Claude web / Grok / Gemini … 有没有？
5. **生图 / 视频 / 多模态**：豆包生图 / 即梦 / 可灵 / Midjourney / LibLib / 智谱生图 / 海螺 … 有没有？
6. **AI 搜索 / 搜索引擎**：Perplexity / 秘塔 / 知乎直答 / 纳米AI搜索 / 4 大 AI 搜索(网关) … 有没有？
7. **浏览器自动化 / CLI 工具**：opencli 已连的引擎 / 其他 RPA … 有没有？
8. **本地模型 / 推理服务**：Ollama / LM Studio / 本地部署 … 有没有？
9. **中转 / 代理**：ZSCC 代理 / one-api、new-api 中转 … 有没有？
10. **办公 / 集成 / 其他**：飞书 / 钉钉 / Notion / Obsidian / 微信 / 企业微信 / Telegram / 代码托管(GitHub等) / 语音 / 文档处理 … 还有没有别的？

### 每类怎么问
1. 先问「这类你有没有？」—— 不要默认他有。
2. 有 → 逐个资源深挖字段（见下）；没有 → 跳下一类。
3. 用户说「想不起来了 / 没有了」时，用框架里**他没提过的类型**去补问，直到确认盘完。

| 字段 | 说明 |

| 账号/资源名 | |

## 产出（台账）
把填完的表落成 Markdown：
```
# AI 资源台账

## [类型] 账号 A
- 平台：xxx
- 模型：xxx
- 额度：xxx（刷新规则 / 过期）
- 访问：xxx
- 用途：xxx
```

## 方法（怎么问 + 怎么查）
- **交互式提问是主方法**：按分类框架逐类问，边问边记，不假设。
- 已知线索可先查：飞书资源表用 `lark-cli`、ai-resource-hub 仓库用 `gh`，避免重复问郭老师已经盘过的。
- 网页额度（如 OpenCode Go）：能抓就抓，抓不到标「待确认」。
- **拿不准宁可标「待确认」，不要编。**

## 反馈记录（干完必须写，简短）
1. 盘出几个资源（数量），按类型分布
2. 额度机制已明确几个、待确认几个
3. 台账文件放在哪（路径）
4. 还有哪些类型郭老师说「以后再说」/ 没覆盖到

## 红线（绝对不能做）
- 不碰任何凭证 / API key / 密码；凭证只在本地 `scheduler/credentials.json`。
- 不创建 / 删除账号，不充值，不绑卡，不订阅。
- 不把凭证写进任何台账 / 汇报 / 聊天。

## 验收标准
- 按分类框架逐类问过了，每个已知资源都有一条台账。
- 额度机制 + 访问方式都填了（或明确标「待确认」）。
- 台账是结构化 Markdown，简短汇报写完了。
